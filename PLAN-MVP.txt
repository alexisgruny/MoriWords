PLAN DE DEVELOPPEMENT - LANGUAGE PIPELINE
==========================================

Objectif
--------
Construire une application personnelle d'apprentissage des langues :
texte japonais -> tokenization -> traduction contextuelle -> cartes de revision.

Le MVP commence par japonais -> francais, mais les interfaces doivent permettre
d'ajouter d'autres langues plus tard.

Etat actuel
-----------
Le MVP est deploye sur Vercel : https://moriwords.vercel.app.
Le projet utilise Next.js 16, TypeScript, Tailwind, Prisma 7 et PostgreSQL.
Le parcours principal fonctionne : texte japonais -> tokenization -> detection
des mots -> JLPT -> traduction mot ou phrase -> deck -> revision SM-2.
Les migrations Prisma sont presentes et le dataset JLPT compact contient
18 459 entrees normalisees. Les mots absents du dataset retournent unknown.
La traduction (mot et phrase) est validee avec un schema Zod, un timeout de
20s et des erreurs claires sans fuite de details internes ; le cache est
verifie en local et en production.
La deduplication des cartes (WordOccurrence), la recherche/suppression de
cartes, l'historique des revisions (ReviewLog) et les statistiques de deck
(cartes dues, taux de reussite) sont implementees.
Les images de cartes (Unsplash) sont operationnelles et validees en reel.
L'audio (ElevenLabs) est code-complet mais bloque : le plan gratuit refuse les
voix de bibliotheque via l'API (402 "paid_plan_required"), meme ajoutees a
My Voices ; mis de cote pour l'instant (voir Priorite 9).
Le flux RSS NHK Easy est bloque : pas de flux officiel et robots.txt interdit
les crawlers IA (voir Priorite 11) ; une source alternative reste a choisir.
Un audit d'accessibilite/responsive a ete fait (labels, focus-visible, un bug
de style manquant corrige) et un test d'integration bout en bout sur la vraie
base a ete ajoute (Priorite 12) ; il manque encore un test manuel reel sur
navigateur/mobile et lecteur d'ecran.
Tests et build passent ; la prochaine etape concerne surtout le choix d'une
source RSS alternative et l'activation reelle d'ElevenLabs/Unsplash avec de
vraies cles API.

Regle de travail
----------------
A chaque etape :
1. Comprendre la notion avant de coder.
2. Implementer le plus petit morceau utile.
3. Tester manuellement et avec un test automatise quand c'est pertinent.
4. Ne passer a l'etape suivante qu'une fois le jalon valide.
