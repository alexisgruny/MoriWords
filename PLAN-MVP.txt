PLAN DE DEVELOPPEMENT - MORIWORDS (LANGUAGE PIPELINE)
=====================================================

Version compactee le 2026-09-28. Le detail complet de chaque priorite (0 a 44 :
constats, choix, validations) reste dans l'historique git :
  git show a8675ff:PLAN-MVP.txt


Objectif
--------
Application personnelle d'apprentissage du japonais (vers le francais) :
texte japonais -> mots analyses -> traduction -> decks -> revision SM-2,
plus des pages de reference et des exercices. Les interfaces (Tokenizer,
paires de langues) restent ouvertes a d'autres langues.

En ligne : https://moriwords.vercel.app (deploiement auto depuis master).
Stack : Next.js 16 (App Router), React 19, TypeScript, Tailwind v4,
Prisma 7 + PostgreSQL (Neon en prod), Vitest, Claude (claude-haiku-4-5).


Regle de travail
----------------
1. Comprendre avant de coder, livrer le plus petit morceau utile.
2. Verifier : tsc, eslint, vitest, et dans un vrai navigateur pour l'UI.
3. Noter ici chaque etape terminee ([TERMINE] / [PARTIEL] / [A FAIRE]).
4. Commit + push sur master une fois verifie, puis suivre le deploiement.


Etat actuel par domaine
-----------------------
Analyse (page /)
- Coller un texte ou en generer un (citation d'anime, actu simplifiee, actu
  nippon.com, dialogue, extrait litteraire) ; tokenisation kuromoji, lecture,
  forme de base, categorie grammaticale en francais, niveau JLPT colore.
- Selection simple ou multiple (Maj pour une plage), panneau d'actions colle
  en bas de l'ecran : traduire, ajouter au deck (ou tout ajouter).
- Guide en 3 etapes, historique des derniers textes (/historique complet).

Decks et revision
- Decks (grille avec barre "a jour"), cartes dedoublonnees par mot et par
  deck (WordOccurrence = textes ou le mot a ete vu), 5 phrases d'exemple
  generees a l'ajout, traduction automatique si pas de sens.
- Revision SM-2 : modes Standard / Kanji / Contexte / Quiz (4 choix), notes
  0-5 en trois tons, barre de session, ecran de fin, raccourcis clavier,
  annulation de la derniere reponse. "Reviser tout" (tous decks confondus).
- Gestion : renommer, editer sens/lecture, selection multiple (deplacer,
  supprimer), mots "en difficulte" (leech), export Anki (TSV).
- Statistiques par deck (dues, taux de reussite, repartition nouveaux / en
  cours / maitrises, mots difficiles, dernieres revisions) ; serie de jours
  de revision (streak) sur l'accueil et les decks.

Reference
- /kana : hiragana et katakana (46 de base, 25 voises, 33 combines par
  ecriture) avec romaji, filtre par groupe, recherche par son ou par kana.
  Pas d'ajout au deck (une carte declencherait traduction + exemples Claude).
- /grammaire (61 points N5-N1), /conjugaison (27 formes), /kanji (2 211
  kanji, sens traduits en francais) : filtre par niveau, recherche, barre
  collee en haut sur tablette/ordinateur ; ajout direct d'un kanji au deck.
- /vocabulaire : tous les mots rencontres, avec recherche et niveau.

Exercices (/exercices)
- Kana (/exercices/kana) : lire un kana, taper son romaji ; corrige
  localement (variantes shi/si, tsu/tu... acceptees), score et reprise des
  erreurs. Pas d'appel serveur, donc pas encore dans /exercices/stats.
- Sous-pages grammaire, conjugaison, kanji (on montre le kanji, l'eleve
  donne le sens), mon vocabulaire. Correction par Claude, sauf kanji
  (comparaison locale aux synonymes).
- /exercices/stats : taux de reussite par type, points a revoir (>= 2
  tentatives et < 80 %) ; /exercices/revision : session ciblee sur ces
  points faibles.

Interface
- Theme "carnet imprime" (Nunito + Noto Sans JP, vermillon), mode sombre
  (preference systeme ou bouton, sans flash au chargement), menu deroulant
  sous la largeur tablette, animations qui respectent prefers-reduced-motion,
  squelettes de chargement, etats vides utiles.
- Contrastes verifies (texte blanc sur vermillon >= 4.5:1 dans les deux
  themes, jeton --accent-hover pour le survol des boutons pleins).


Decisions et contraintes a connaitre
------------------------------------
- Pas de scraping contraire aux conditions d'un site : NHK Easy est bloque
  (pas de flux officiel, robots.txt interdit les crawlers IA). Source news
  reelle = flux RSS officiel de nippon.com (titre + resume du flux seulement,
  jamais la page complete). Autres contenus generes par Claude.
- Images et audio par carte (Unsplash / ElevenLabs) : construits puis
  supprimes du code et de la base le 2026-09-27, jamais utilises.
- Economie de tokens Claude : caches en base pour les traductions
  (TranslationCache), les exemples par mot (LemmaExampleCache), les
  corrections d'exercice (ExerciseCorrectionCache, + reponse identique a la
  reference acceptee sans appel), phrases de grammaire generees une seule
  fois par point (GrammarExercise), kanji corriges localement. Les
  generateurs de contenu du jour ne sont volontairement pas mis en cache.
- Niveaux JLPT : listes non officielles (egg rolls JLPT 10k + listes de
  Jonathan Waller pour separer N5/N4), recalculees a la lecture ; un mot
  absent renvoie "unknown", jamais devine.
- Contenu francais statique verifie par un correcteur orthographique
  (nspell + dictionary-fr) dans les tests ; liste d'exceptions pour le
  vocabulaire japonais romanise.
- Securite en attendant des comptes (Priorite 45) : textes limites en taille
  (analyse 10 000 car., traduction 2 000), 200 requetes / 10 min par IP sur
  les 9 routes qui peuvent appeler Claude, budget global d'appels reels a
  Claude (200/heure, 600/jour, reglables par CLAUDE_MAX_CALLS_PER_HOUR /
  _PER_DAY), compteurs en base (RateLimitCounter). DELETE/PATCH des decks
  et cartes reserves au proprietaire (OWNER_SECRET + cookie signe).
- Comptes utilisateurs (Priorite 47, phase 1) : Better Auth, email + mot de
  passe (hache) et Google, pages /connexion et /inscription, bouton de compte
  dans la nav. Colonne userId (optionnelle) sur Deck, SourceText,
  ExerciseAttempt ; le premier compte cree avec OWNER_EMAIL recupere les
  donnees existantes. Installe avec legacy-peer-deps (.npmrc) a cause d'un
  peer optionnel Vite 8.
- Tests d'integration sur la vraie base locale : n'injecter que DATABASE_URL
  dans Vitest (jamais les cles API), utiliser des decks jetables
  "safe to delete" et des lemmes que chaque fichier est seul a utiliser
  pour les caches partages. 3 tests d'integration peuvent expirer sous
  charge parallele ; ils passent seuls.


Points ouverts
--------------
- [A FAIRE] Comptes, phase 2 : chaque route filtre par l'utilisateur
  connecte (decks, cartes, textes, tentatives), pages protegees, puis
  retrait de la protection OWNER_SECRET.
- [A FAIRE par l'utilisateur] Variables Vercel pour les comptes :
  BETTER_AUTH_SECRET (aleatoire, 32+ caracteres), BETTER_AUTH_URL
  (https://moriwords.vercel.app), OWNER_EMAIL (son email, AVANT de creer son
  compte), et pour Google GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET (Google
  Cloud, URI de redirection
  https://moriwords.vercel.app/api/auth/callback/google).
- [A FAIRE par l'utilisateur] Definir OWNER_SECRET dans les settings Vercel
  (mot de passe long et aleatoire), puis deverrouiller son navigateur sur
  /proprietaire. Sans lui, en production, personne ne peut supprimer,
  renommer, modifier ni deplacer (protection fermee par defaut).
- [A FAIRE par l'utilisateur] Definir CRON_SECRET dans les settings Vercel
  pour activer l'import quotidien nippon.com (vercel.json pret ; le bouton
  manuel fonctionne sans).
- [PARTIEL] Accessibilite : axe-core a 0 violation, focus et navigation
  clavier verifies ; manque un test avec un vrai lecteur d'ecran
  (VoiceOver / NVDA / TalkBack) sur appareil physique.
- [PARTIEL] Traduction automatique des mots sans sens : deck par deck, pas
  de bouton "tous les decks".
- [PARTIEL] "Maitrise" = intervalle SM-2 >= 21 jours (seuil arbitraire) ;
  pas encore de courbe de progression par jour/semaine.
- [PARTIEL] Colonnes VocabularyEntry.difficulty et TranslationCache.difficulty
  encore ecrites mais plus lues (niveau recalcule) : a supprimer un jour.
- [PARTIEL] Jeu de grammaire (61 points) a etendre au fil de l'eau dans
  src/lib/grammar/points.ts (id unique prefixe par le niveau, teste).
- [BLOQUE] Categorie de contenu "gaming" : aucune source propre validee.
- [A FAIRE] Strategie CEFR si l'anglais est ajoute un jour.


Architecture
------------
- src/app/ : pages et routes API (analyse, decks, reference, exercices,
  historique, cron).
- src/components/ : nav, theme, review-controls (notes, session),
  reference-toolbar (filtres, recherche), translation-exercise, etc.
- src/lib/tokenizer/ : interface Tokenizer + kuromoji (japonais).
- src/lib/translation/ : traduction Claude + cache.
- src/lib/decks/ : exemples, traduction auto, utilitaires de cartes, export.
- src/lib/srs/ : SM-2 et streak (logique pure, testee).
- src/lib/difficulty/ : dataset JLPT et classification.
- src/lib/grammar/, conjugation/, kanji/ : referentiels, exercices,
  statistiques d'exercice.
- src/lib/feeds/ : sources de contenu (RSS nippon.com, generateurs Claude).
- src/lib/spellcheck/ : verification orthographique du contenu statique.
- scripts/ : regeneration des datasets JLPT et kanji.
- prisma/ : schema et migrations.
